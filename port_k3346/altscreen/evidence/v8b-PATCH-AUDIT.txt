K2161 v8B STOCK-COMPASS / OBSERVE-ONLY PATCH AUDIT
==================================================

Purpose
-------
Remove the two state overrides that were fighting the Audi factory CarPlay
navigation presentation:

1) Native v8A no longer rewrites CarPlay TurnByTurn ownership from 1 -> 0.
   It still observes the ORIGINAL turns value and keeps the existing v8A
   route/idle ViewArea switching logic.

2) The custom RGI JAR uses its already-existing HUD-only/non-VC path instead
   of the dev.4 FACTORY_RGI path, so it no longer forces favored VC mode=RGI.

Native binary provenance
------------------------

  SHA256 5039533d882e8bac6ebb979be8a1b0ef794e11b2d71144ce83f2d9ec494d1069
  size   298059

Patch is exactly two ARM instructions, 8 bytes total:
  file/VA 0x0000ad64: e5842014 (str r2,[r4,#20]) -> e1a00000 (ARM NOP)
  file/VA 0x0000ae64: e5842014 (str r2,[r4,#20]) -> e1a00000 (ARM NOP)

Those stores were the two compiled control-flow copies of:
  out->turns = 0;

No other native byte is changed from v8A.

NOTE: the v8A log format still contains a `stock=` field and may log 0 in the
route branch because this is a deliberately minimal binary patch. The actual
mode-state struct is no longer overwritten; use ORIGINAL/route state and live
behaviour as the authority.
